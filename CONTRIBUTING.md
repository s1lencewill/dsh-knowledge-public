# Contributing

This is a preparation snapshot. Original contributions are Apache-2.0. The proposed public issue/PR destination has not been created or permission-verified. Use synthetic fixtures; never commit personal corpora, captures, session logs, keys or machine runtimes. Keep engine contracts and TypeScript/browser consumers consistent. Run `npm run build`, Node tests and Python tests with a local Python 3.13 environment. Runtime-dependent tests require separately prepared tools and runtime; report missing prerequisites as skipped or blocked, not passed. No real model calls are needed for local regressions.
