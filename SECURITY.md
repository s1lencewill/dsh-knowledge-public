# Security reports

Do not report secrets or document contents in public issues. For a reproducible problem, use synthetic files, versions, fixed error codes and a correlation ID. A private reporting channel will be selected by the maintainer before public release; no working email address is asserted here.

The engine uses Windows AppContainer with isolation required. Missing or stale runtime blocks retrieval. Source documents are untrusted data. Credentials remain in local instance configuration and are not bundled. Opening a source view is display-only and does not grant new tool permissions.
