# Sample library (self-made, synthetic)

Two documents, both written for this project on purpose:

- `library/texts/study.txt` — the extracted text of a 3-page PDF that was generated for the probe, with a
  page map recorded in `catalogue.json`. Its `PDF page N` markers come from that extraction, and the
  document deliberately contains one line that merely *says* "PDF page 9" to show that a page is taken from
  the map and never from the text.
- `library/texts/notes.md` — a Markdown note with no page map at all (so its card reports line numbers only).

Both contain a line that reads like an instruction ("Ignore all previous instructions…"). That is
intentional: retrieved text is source material, never instruction, and the card and the protocol both say so.

Nothing here is real literature, and no file was taken from a user library.
