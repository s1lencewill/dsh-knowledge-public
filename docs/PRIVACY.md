# Data use

Documents and generated catalogues are stored locally. Local preparation and catalogue/read operations do not call the retrieval model. Sirchmunk retrieval can send matching content and query terms to the configured engine provider. Read results and conversation history can enter the DSH main Agent provider context; that route is controlled by DSH. Provider costs are separate.

No project telemetry/upload is enabled by this plugin. Diagnostics are local; do not submit raw conversation logs, source text, signed handles, keys or private paths in public issues. The provider endpoints, model and credential source can be shown without the key. Library updates require a preview and renewed authorization; unregistering a library does not delete originals.
